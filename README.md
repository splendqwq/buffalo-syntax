# Buffalo Syntax Club · 水牛语法俱乐部

一个毫无意义、但解释很认真的 Buffalo 句子游乐场。

输入一个数字，生成恰好这么多个 `buffalo` 组成的句子。看看每个词在做什么，以及水牛们到底在欺负谁；也可以亲自编辑比赛，让句子和图一起变化。

代码与项目内的 SVG 图形采用 **[MIT License](./LICENSE)**。

## 有什么好玩

- **一个词，三种身份**：`Buffalo` 表示地名“布法罗”，`buffalo` 可以是复数名词“水牛”或动词“欺负”。每个词都有词性、指代与修饰对象。
- **随机恩怨树**：相同词数也能抽出不同的比赛。随机生成从 7 词起保证分叉，经典 8 词读法可单独体验。
- **联动可视化**：点单词、修饰框、水牛或箭头，查看对应范围和对象。比赛图支持缩放、平移、双指操作与全屏。
- **图和句子双向编辑**：添对手、改欺负对象、换产地、撤掉整条分支；文字草稿可先预览不同读法，再应用。提供 50 步撤销／重做。
- **Q 弹蹦迪**：让界面和水牛一起蹦起来。可选择自己的音频并填写 BPM，单词每拍起跳，水牛和板块每两拍起跳；支持调音量、拖进度、对齐重拍。
- **水牛也会嘴硬**：随机绰号、表情与 100 多条情境台词。牛群拥挤时自动减轻动画。

## 三步开玩

1. 选择 **1–1,000** 的词数，点击“开赛”。数字表示句子里的单词数量，水牛按图中的组号区分。
2. 点单词看它的身份，点图里的水牛看恩怨；箭头从欺负者指向被欺负者。
3. 点击“在图里改”，或展开“直接编辑句子”。不满意就撤销；点 Q 弹可以随时蹦起来，关闭开关或按 `Esc` 落地。

## 音乐与 BPM

点击“选择音频”，从自己的设备选择 MP3、M4A、WAV 等音频，再填写 **30–300 BPM** 并点击“应用速度”。默认 120 BPM，可输入小数；如果蹦得太快或太慢，也可以尝试半速或双速。

打开 Q 弹开始播放，关闭则暂停。播放格式取决于浏览器。听到音乐重拍时点击“对齐重拍”，可调整动作与音乐的起点。

音频由浏览器读取本机文件并播放，刷新页面后需要重新选择。

## 需要知道的事

- 这是明确标注括号范围的语言实验。深度嵌套可能很难读，同一名词上叠加多个省略关系词的从句，其自然英语可接受性有争议。详见 [解释规则](./docs/GRAMMAR.md)。
- 图编辑始终保持项目规则内的有效结构。文字草稿无效时不能应用，正式句子与图继续保持有效；系统会提供可以应用的修复建议。
- 本站用大写 `Buffalo` 标注地名。编辑时请保留大小写，以区分地名和其他词性；支持 `buffalo`／`Buffalo` 及可选的句末标点。
- 大句子会增加设备负担。80 词起 Q 弹自动进入轻量模式，较弱的手机仍可能卡顿；可减少词数或关闭动画。
- 刷新页面会重新开始比赛。
- 使用现代浏览器。浏览器不支持原生全屏时，使用窗口内铺满的舞台。
- 字体由 Google Fonts 提供；连接失败时使用系统字体。第三方字体说明见 [NOTICE](./NOTICE.md)。

## 自己运行

安装 [Node.js](https://nodejs.org/) **20 或更新版本**，下载并解压项目，在项目目录打开终端执行：

```sh
npm run dev
```

然后在浏览器打开 **http://127.0.0.1:5173**。Windows PowerShell 如果提示禁止运行脚本，可改用 `npm.cmd run dev`。

通过上述地址访问网页，让浏览器正确加载脚本模块。开发服务器监听本机地址，可通过环境变量 `PORT` 自定义端口。

## 放一个试玩网页

这是纯静态网站：计算和图形渲染都在访客浏览器里运行，可直接部署到 Cloudflare Pages 或 GitHub Pages。

生成发布目录：

```sh
npm run build
```

将生成的 **`dist/`** 上传到静态托管平台。路径支持 GitHub Pages 的仓库子目录。

发布前可在本机检查：

```sh
npm run preview
```

具体的拖拽上传步骤、Git 集成配置及平台限制见 [部署说明](./docs/DEPLOYMENT.md)。

## 开发与贡献

```sh
npm test       # 核心解释器、编辑、节拍与发布边界测试
npm run build # 更新 dist，重建时会清空旧 dist
```

- `src/engine.js`：语法树校验、句子生成与逐词解释。
- `src/editor.js`、`src/editing.js`：安全编辑、草稿解析与历史。
- `src/arena.js`、`src/syntax.js`、`src/camera.js`：比赛图、修饰视图与镜头。
- `src/audio.js`、`src/beat.js`、`src/jelly.js`：本机音频、BPM 与动画。
- `scripts/build.mjs`：发布文件白名单。
- `tests/`：使用 Node.js 内置测试框架。

欢迎提交问题和改进。修改语法或编辑逻辑时，请保留词数、对象引用、修饰范围与原子提交的测试。提交的素材请注明来源与分发许可。
